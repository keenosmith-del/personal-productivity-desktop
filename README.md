# Flagship Project – Full-Stack Productivity Platform

## Overview

This project is a full-stack productivity platform built using the MERN stack (MongoDB, Express.js, React, and Node.js) to demonstrate modern software engineering principles, secure authentication, RESTful API development, and scalable full-stack application architecture.

The platform integrates multiple productivity modules—including tasks, projects, goals, reminders, notes, folders, calendar management, and user accounts—into a single cohesive application. It showcases production-style development through secure authentication, complete CRUD operations, modular frontend and backend architecture, MongoDB data persistence, and clean separation of concerns across the application.
